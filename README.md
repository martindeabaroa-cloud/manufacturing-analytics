# Furniture BOM & Cost Calculation System

## Descripción
Sistema completo de gestión de Bill of Materials y cálculo de costos para línea de productos de mobiliario. Proyecto realizado con metodología de análisis de procesos, estructura de datos y optimización de costos.

## Características
- Gestión de Bill of Materials para 50+ productos
- Catálogo completo de insumos, herrería y madera
- Modelo de cálculo automático de costos unitarios
- Análisis de componentes y precios por categoría
- Optimización de cortes y planificación de producción
- Explosión de compras y análisis de materiales

## Tecnologías utilizadas
- Excel avanzado (tablas dinámicas, VLOOKUP, fórmulas complejas)
- Power Query
- Análisis y modelado de datos

## Estructura
- **Productos**: Catálogo de 50+ artículos de mobiliario
- **Insumos**: Base de datos de componentes pequeños y hardware
- **Herrería**: Componentes de acero y metales
- **Madera**: Materiales madereros con cálculo de m²
- **BOM**: Bill of Materials por producto
- **Costo Producto**: Cálculo unitario de costos
- **Optimizados**: Análisis de desperdicio y optimización de cortes
