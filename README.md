# Furniture BOM & Cost Calculation System

## Descripción
Sistema completo de gestión de Bill of Materials y cálculo de costos desarrollado para empresa de mobiliario.

## Responsabilidades
- Relevamiento de procesos y análisis de 50+ productos
- Estructuración de Bill of Materials (BOM) completa
- Diseño de modelo de cálculo automático de costos
- Análisis de componentes, materiales y proveedores
- Optimización de estructura de precios

## Tecnologías
- Excel avanzado (tablas dinámicas, VLOOKUP, fórmulas complejas)
- Power Query
- Análisis de datos y modelado

## Resultado
Implementación exitosa de sistema de costeo que permite cálculo automático de precios por producto y análisis de optimización de materiales.

*Nota: Datos confidenciales de la empresa. Disponibles bajo NDA.*
